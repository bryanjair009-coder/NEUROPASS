Política de privacidad de NEUROpass

NEUROpass es una aplicación de control parental que funciona sin internet. Toda la información se guarda únicamente en el teléfono donde está instalada.

Última actualización: septiembre de 2026 · Aplica a la app Android com.poslabs.neuropass

Resumen

No hay servidor, no hay cuentas de usuario y la aplicación no realiza ninguna petición de red. Nada de lo que la app guarda sale del dispositivo.
  • No recopilamos datos personales.
  • No compartimos información con terceros.
  • No hay publicidad ni herramientas de analítica.
  • La copia de seguridad automática de Android está desactivada, así que los datos tampoco se suben a Google Drive.

No se guarda el enunciado del reto ni la opción que el menor eligió, ni fecha de nacimiento, correo, teléfono, escuela, ubicación, contactos, fotos, micrófono ni identificadores de publicidad. La base de datos de la aplicación no tiene ningún campo para esa información.

Del tutor

El PIN y el código de recuperación no se guardan tal cual: se almacena una transformación criptográfica suya en el almacén seguro del sistema Android (Keystore), que es el mismo mecanismo que usan las aplicaciones bancarias.

Menores de edad

NEUROpass está pensada para que un adulto la instale y la configure en el teléfono de un menor. Como no se recopila ninguna información y nada sale del dispositivo, no hay datos de menores que se transmitan, se vendan o se compartan. La aplicación no incluye publicidad, compras ni enlaces a redes sociales.

Cómo borrar los datos

En la propia aplicación: panel del tutor → Ajustes → Borrar todos los datos. Elimina perfiles, progreso, respuestas escritas y el PIN. También puede borrarse todo desinstalando la aplicación. No hay copias en ningún otro sitio, así que no hace falta solicitar nada por correo.

Cambios en esta política

Si en el futuro la aplicación incorpora funciones que necesiten enviar información —por ejemplo, un panel para consultar el progreso desde otro teléfono—, esta página se actualizará antes de publicar esa versión y se explicará qué se envía y por qué.
